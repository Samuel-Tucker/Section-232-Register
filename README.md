# Section 232 Invoice Register

Shipping to the USA? Keep a verified Section 232 and metal-composition answer per product and click-to-copy it onto every commercial invoice. One self-contained HTML file; runs in your browser and nothing is uploaded.

Use it online: https://sams.help/tools/section232-register

Or download `index.html` and open it in any browser. There is nothing to install and nothing is sent anywhere.
